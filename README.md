# Ersunny Travel — Transfer aeropuerto Punta Cana

Sitio de reservas para traslados privados del Aeropuerto Internacional de Punta Cana (PUJ) a hoteles en **Punta Cana**, **Bávaro** y **Macao**, más excursiones.

## Sitio en vivo

https://zukiskyrim02-arch.github.io/ersunny-travel/

## Panel admin

https://zukiskyrim02-arch.github.io/ersunny-travel/#/admin

Contraseña por defecto: `ErsunnyAdmin2026`

Desde el admin puedes gestionar precios por zona, tipos de vehículo, excursiones y reservas. Los datos se guardan en el navegador (localStorage).

## Desarrollo

```bash
npm install
npm run dev
```

Admin local: http://localhost:5173/#/admin

## Build

```bash
npm run build
npm run preview
```
